IMPORTANT LIMITATIONS
- This is a verified source ZIP, not a compiled or signed Windows installer.
- A Windows .exe must be built on Windows using BUILD-DESKTOP-WINDOWS.bat.
- The AI Co-Pilot requires Ollama and a separately installed model; no model is bundled.
- Windows-only integrations need Windows and the permissions documented by the app.
- Heuristic detections are indicators for review, not proof that a file is malicious.
- The 14-feature 2.3.0 expansion has NOT been represented as completed in this package.

QUICK START
1. Extract the ZIP to a normal folder.
2. Install Node.js LTS.
3. Run RUN-DESKTOP-DEV-WINDOWS.bat.
4. To build the Windows installer, run BUILD-DESKTOP-WINDOWS.bat and check dist/.

For AI setup, see README-AI-MODEL.md and SETUP-AI-MODEL-WINDOWS.bat.
