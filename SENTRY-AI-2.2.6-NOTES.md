CyberShield AI 2.2.6 — SENTRY Robotics AI Companion

New:
- SENTRY AI companion in sentry.html.
- Local-model availability check and AI chat through the project's existing backend API.
- Telemetry explanation, safe route strategy, and robotics learning prompts.
- Simulated proximity/confidence/battery sensor lab and calibration action.

Safety and accuracy:
- This remains a virtual grid simulation. No physical robot or external hardware is connected.
- Sensor lab values are illustrative simulation values, not real sensor readings.
- AI output is advisory and does not execute robot commands.
- Start Ollama and the configured CyberShield local backend to use AI. The rest of the simulation works without AI.

Run:
  npm install
  npm run check
  npm test
  npm start
