# CyberShield AI 2.3.0 — PKCERT assisted reporting

- Added an official PKCERT reporting section to Automation Center.
- Added a local report builder for incident category, approximate date, affected organization/system, impact, and a brief summary.
- Requires an explicit privacy confirmation before generating the JSON report.
- The report is downloaded locally. It is **not** automatically transmitted to PKCERT.
- The official PKCERT reporting form opens only when the user clicks the link/button.
- The UI distinguishes PKCERT's organizational/technical incident scope from individual cybercrime complaints.

Official destination verified: https://pkcert.gov.pk/report-incident/

PKCERT's form states that it is intended for incidents affecting organizations, networks, systems, or critical infrastructure. It excludes individual cybercrime complaints such as online fraud, harassment, blackmail, and fake accounts.
