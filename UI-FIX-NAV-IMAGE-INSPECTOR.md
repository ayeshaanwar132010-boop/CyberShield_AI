# UI fixes — navigation and Image Inspector

- Desktop primary navigation now stays on one horizontal line with compact, consistent link styling. If the window is too narrow to display every item at once, the navigation row scrolls horizontally instead of wrapping or colliding. Mobile navigation remains a vertical menu.
- Image Inspector upload area is now one centered full-width drop zone with a separate Browse image button. The file input is no longer nested inside a styled label, avoiding the narrow split upload appearance. Selected images render inside one contained preview frame.
- No scanner, training, or analysis behavior was intentionally changed.
