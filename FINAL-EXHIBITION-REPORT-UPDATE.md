# CyberShield AI — Final Exhibition Report Update

## Shareable report generation
After a message or URL is analyzed in Security Center, use **Generate shareable report**.

The app creates a standalone HTML report that can be opened, printed to PDF, emailed, or shared.

### Report contents
- Incident ID
- Date/time
- Analysis type
- Heuristic risk score and assessment
- Detected warning indicators
- Privacy-redacted sample excerpt
- Recommended handling
- Human-review reminder

### Privacy protection
The generated report attempts to redact passwords, OTP/verification codes, PIN/CVV, recovery phrases, payment numbers, and email addresses. Users should still review the report before sharing.

### Important
The report is an educational risk assessment, not proof of malicious activity or a professional investigation. Official reporting should be reviewed by a human before submission.
